# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project uses [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Reading list: books to read, kept in the browser — add, reorder, note, mark as finished, remove.
- Photo gallery: the arrow keys step through the open photo.

## [1.0.0] — 2026-10-07

### Added

- Catalogue search with format chips, an availability filter, subject browsing and paged results.
- Item details with the catalogue record, and reservation for pickup at a chosen branch.
- My loans: sortable table, single and bulk renewal, CSV export, fines and the next due date.
- Home page with opening hours, events page with the latest storytime recording, and a photo gallery.
- Settings for compact results, loan reminders and home branch, kept in the browser.
- Staff notice banner and confirmation toasts.
