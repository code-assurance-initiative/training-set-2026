# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.0.0] - 2026-10-07

### Added

- Vehicles, work orders (lines, pricing, approval) and inspections with automatic repair work orders.
- Due-maintenance from the live telematics odometer, and hourly reminder e-mails from the worker.
- Fleet dashboard, health checks, JWT scope policies and security headers.
- Architecture tests for the layering and contracts decisions.
