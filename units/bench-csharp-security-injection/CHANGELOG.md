# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses [Semantic Versioning](https://semver.org/).

## [1.2.0] - 2026-10-05

### Added
- Webhook test endpoint; callbacks connect only to addresses the callback policy accepts.
- Partner feed pull, restricted to configured hosts.
- Bundle import for files exported by the desktop client.

## [1.1.0] - 2026-09-24

### Added
- Report exports through LibreOffice, with thumbnails.
- Password-protected share links.
- Metadata preview and document cards for the archive front end.

## [1.0.0] - 2026-09-10

### Added
- Document search, document listing, attachments, saved searches and report definitions.
