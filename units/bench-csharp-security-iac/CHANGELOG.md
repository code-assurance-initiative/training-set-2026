# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses semantic versioning.

## [1.2.0] - 2026-10-07

### Added
- Pull request preview images, issue triage labels and a pull request labeler.
- Log forwarder DaemonSet for the namespace's container logs.

## [1.1.0] - 2026-09-21

### Added
- Reminder worker that posts upcoming arrivals to the yard team's chat channel.

## [1.0.0] - 2026-09-02

### Added
- Dock booking API with PostgreSQL storage, Kubernetes manifests and release pipeline.
